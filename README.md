# 3DMoleculeSimulator

# 🧪 분자 모형 탐험실 (Molecule Model Simulator)

분자의 구조와 입체적인 형태를 시각적으로 탐구할 수 있는 교육용 웹페이지입니다.

분자 이름을 검색하면 2D 구조식과 다양한 3D 분자 모형을 확인할 수 있습니다.

---

## 1. 프로젝트 소개

이 프로젝트는 화학 시간에 배우는 분자의 구조를 직접 관찰하고 이해할 수 있도록 제작한 웹 애플리케이션입니다.

분자 이름을 입력하면 PubChem 데이터베이스에서 분자 정보를 검색하고, 3Dmol.js를 이용하여 입체적인 분자 모형을 표시합니다.

### 프로젝트 목표

- 분자의 원자와 화학 결합을 시각적으로 이해하기
- 2D 구조식과 3D 분자 모형 비교하기
- 공-막대 모형과 공간 채움 모형의 차이 이해하기
- 분자식과 분자량 등 화학 정보 확인하기

---

## 2. 주요 기능

### ① 분자 검색

영어 분자 이름을 입력하면 해당 분자의 정보를 검색합니다.

| 물질 | 검색어 |
|---|---|
| 물 | water |
| 에탄올 | ethanol |
| 포도당 | glucose |
| 벤젠 | benzene |
| 아세톤 | acetone |
| 카페인 | caffeine |

### ② 공-막대 모형 (Ball-and-Stick Model)

원자를 공으로, 원자 사이의 화학 결합을 막대로 표현합니다.

- 원자의 연결 관계
- 화학 결합의 배열
- 분자의 입체적인 형태

### ③ 공간 채움 모형 (Space-Filling Model)

원자의 크기와 분자가 차지하는 공간을 표현합니다.

### ④ 2D 구조식 (2D Structure)

분자의 원자들이 어떤 순서와 방식으로 연결되어 있는지 평면으로 보여줍니다.

### ⑤ 회전 가능한 3D 모형

마우스로 분자 모형을 직접 조작할 수 있습니다.

- 마우스 드래그: 분자 회전
- 마우스 휠: 확대 및 축소

### ⑥ 분자 정보

| 정보 | 설명 |
|---|---|
| 분자식 | 분자를 구성하는 원자의 종류와 개수 |
| 시성식 | 분자의 구조적 특징을 나타내는 식 |
| 실험식 | 원자 개수의 가장 간단한 정수비 |
| 화학식량 / 몰 질량 | 분자의 상대적인 질량 또는 몰당 질량 |
| 녹는점 | 고체가 액체로 변하는 온도 |
| 끓는점 | 액체가 기체로 변하는 온도 |
| 25°C 밀도 | 25°C에서의 물질 밀도 |
| 인화점 | 증기가 점화될 수 있는 온도 조건을 나타내는 값 |

※ 일부 물성 정보는 현재 버전에서 실제 데이터베이스와 연결되어 있지 않아 자료 확인이 필요하다고 표시될 수 있습니다.

## 4. 데이터 출처

### PubChem

https://pubchem.ncbi.nlm.nih.gov/

미국 국립보건원(NIH)에서 제공하는 화학물질 데이터베이스입니다.

분자식, 분자량, 분자 구조 등의 정보를 검색하는 데 사용합니다.

### 3Dmol.js

https://3dmol.org/

웹 브라우저에서 분자의 3차원 구조를 시각화할 수 있도록 지원하는 JavaScript 라이브러리입니다.

## 5. 실행 방법

### 방법 A. 컴퓨터에서 직접 실행

1. GitHub 저장소에서 `index.html` 파일을 다운로드합니다.
2. 다운로드한 파일을 더블 클릭합니다.
3. Chrome 또는 Edge 브라우저에서 엽니다.
4. 분자 이름을 입력합니다.
5. 검색 버튼을 누르면 분자 모형이 나타납니다.

별도의 프로그램 설치는 필요하지 않습니다.

단, PubChem과 3Dmol.js의 외부 자료를 불러오기 위해 인터넷 연결이 필요합니다.

### 방법 B. GitHub Pages로 웹사이트 공개

1. GitHub에 로그인합니다.
2. 프로젝트 저장소를 엽니다.
3. `index.html`과 `README.md` 파일이 저장소 최상위 폴더에 있는지 확인합니다.
4. 저장소의 **Settings** 메뉴를 클릭합니다.
5. 왼쪽 메뉴에서 **Pages**를 선택합니다.
6. Build and deployment 항목에서 Source를 `Deploy from a branch`로 설정합니다.
7. Branch를 `main`으로 선택합니다.
8. 폴더를 `/(root)`로 선택합니다.
9. **Save** 버튼을 누릅니다.
10. 배포가 완료되면 GitHub Pages 주소로 접속합니다.

---

## 7. 사용 시 주의 사항

1. 분자 검색에는 인터넷 연결이 필요합니다.
2. PubChem에 등록되지 않은 물질은 검색되지 않을 수 있습니다.
3. 모든 물질에 3D 구조 데이터가 제공되는 것은 아닙니다.
4. 일부 물성 정보는 데이터베이스에 값이 없거나 현재 프로그램에서 조회하지 못할 수 있습니다.
5. 시성식은 분자마다 구조를 확인하여 작성해야 하므로 현재 버전에서는 일부 물질에 대해 표시하지 않습니다.
6. 현재 2D 구조 그림은 루이스 구조식이나 유기물 골격 구조식과 완전히 동일하지 않습니다.
7. 교육용 프로그램이므로 실험이나 화학물질 안전 판단의 공식 자료로 사용해서는 안 됩니다.

## 9. 제작 목적

이 프로젝트는 화학을 배우는 학생들이 분자의 구조를 직접 관찰하면서 화학 결합과 분자의 입체적인 형태를 쉽게 이해하도록 돕기 위해 제작되었습니다.

단순히 분자식을 외우는 데 그치지 않고, 분자를 직접 검색하고 회전시키며 관찰하는 경험을 제공하는 것이 목적입니다.
