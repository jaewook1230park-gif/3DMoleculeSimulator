# 3DMoleculeSimulator
# 🧪 분자 모형 탐험실

분자의 구조를 다양한 모형으로 살펴볼 수 있는 웹페이지입니다.  
분자 이름을 검색하면 2D 구조식과 3D 분자 모형을 확인할 수 있습니다.

## ✨ 주요 기능

- **분자 검색**: 영어 분자 이름으로 검색
- **공-막대 모형**: 원자와 화학 결합을 입체적으로 표현
- **공간 채움 모형**: 원자의 크기와 분자의 공간적 형태 표현
- **2D 구조식**: 분자의 원자 연결 구조 확인
- **3D 회전**: 마우스를 이용해 분자 모형 회전 및 확대·축소
- **분자 정보**: 분자식, 시성식, 실험식, 몰 질량 등의 정보 표시

## 🧬 검색 가능한 분자 예시

| 분자 | 영어 이름 |
|---|---|
| 물 | water |
| 에탄올 | ethanol |
| 포도당 | glucose |
| 벤젠 | benzene |
| 아세톤 | acetone |
| 카페인 | caffeine |

## 🚀 실행 방법

### 방법 1. 내 컴퓨터에서 실행하기

1. 저장소에서 `index.html` 파일을 다운로드합니다.
2. 다운로드한 파일을 더블 클릭합니다.
3. Chrome 또는 Edge 브라우저에서 엽니다.
4. 분자 이름을 입력하고 검색합니다.

별도의 프로그램 설치는 필요하지 않습니다.

**주의:** 분자 데이터와 3D 구조를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.

### 방법 2. GitHub Pages로 공개하기

1. GitHub 저장소를 엽니다.
2. `index.html`과 `README.md` 파일을 업로드합니다.
3. 저장소의 **Settings** 메뉴를 클릭합니다.
4. 왼쪽 메뉴에서 **Pages**를 선택합니다.
5. Build and deployment에서 Source를 **Deploy from a branch**로 설정합니다.
6. Branch를 `main`, 폴더를 `/ (root)`로 선택합니다.
7. **Save**를 클릭합니다.
8. 배포가 완료되면 생성된 웹사이트 주소로 접속합니다.

분자 구조 및 분자 정보는 PubChem 데이터베이스를 이용합니다.

## ⚠️ 참고 사항

- 인터넷 연결이 필요합니다.
- 일부 분자는 3D 구조 데이터가 제공되지 않을 수 있습니다.
- 녹는점, 끓는점, 밀도, 인화점 등 일부 물성 정보는 현재 버전에서 실제 데이터베이스 조회가 구현되지 않아 표시되지 않을 수 있습니다.
- 루이스 구조식의 비공유 전자쌍과 유기물의 골격 구조식은 향후 개선이 필요한 기능입니다.
- 이 웹페이지는 화학 교육 및 학습을 위한 참고용입니다.
